# x86 (32-bit MASM) 사칙연산 및 범용 레지스터 출력 프로그램

Win32 콘솔 환경에서 두 개의 부호 있는 32비트 정수를 입력받아 사칙연산(`ADD`, `SUB`, `IMUL`, `IDIV`)을 수행하고, 각 연산 직후의 범용 레지스터(`EAX`, `EBX`, `ECX`, `EDX`) 상태를 32비트 16진수(8자리)로 출력하는 어셈블리 프로그램입니다.

---

## 주요 기능

* **UTF-16 유니코드 콘솔 입출력**: Windows API(`ReadConsoleW`, `WriteConsoleW`)를 직접 호출하여 콘솔 코드페이지 설정과 무관하게 한글 안내 메시지를 안정적으로 출력합니다.
* **부호 있는 10진수 문자열 파싱 (`WStrToInt`)**: 공백 처리 및 양수(`+`)·음수(`-`) 부호를 지원하는 32비트 정수(`SDWORD`) 변환 기능을 구현했습니다.
* **사칙연산 및 레지스터 추적**: 덧셈, 뺄셈, 곱셈, 나눗셈 수행 직후의 `EAX`, `EBX`, `ECX`, `EDX` 레지스터 값을 8자리 대문자 16진수로 출력합니다.
* **API 호출 시 레지스터 보존 (`PrintRegs`)**: Win32 API 호출 규약(`stdcall`)에 의해 `EAX`, `ECX`, `EDX`가 덮어씌워지는 것을 방지하기 위해 스택(`PUSH`/`POP`) 및 스택 오프셋(`[esp + n]`)을 이용해 연산 직후의 레지스터 상태를 안전하게 백업한 뒤 출력합니다.

---

## 개발 및 실행 환경

* **OS**: Windows (32-bit / 64-bit WoW64 호환)
* **Assembler & Linker**: Microsoft Macro Assembler (`ml.exe`), Microsoft Incremental Linker (`link.exe`)
* **라이브러리**: `kernel32.lib`

### 빌드 및 실행 방법

소스 파일명을 `test3.asm`으로 저장한 뒤, MASM 환경이 구성된 터미널(Developer Command Prompt 또는 VS Code 터미널)에서 아래 명령어를 실행합니다.

```powershell
# 1. 어셈블 (오브젝트 파일 생성)
ml /c /coff test3.asm

# 2. 링크 (콘솔 실행 파일 생성)
link /subsystem:console test3.obj

# 3. 프로그램 실행
.\test3.exe
```

> **VS Code 사용자 팁**: `.vscode/tasks.json`이 설정되어 있다면 `test3.asm` 저장(`Ctrl + S`) 후 `Ctrl + Shift + B`로 바로 빌드할 수 있습니다.

## 코드 구조 및 동작 원리

### 1. 프로시저 구성

| 프로시저명 | 역할 | 입력 / 반환 |
| :--- | :--- | :--- |
| **`main`** | 표준 입출력 핸들을 획득하고, 두 정수를 입력받아 4가지 연산과 레지스터 출력을 순차 실행 | - |
| **`WStrToInt`** | `inBuf`에 저장된 UTF-16 문자열을 32비트 부호 있는 정수로 변환 | **반환**: `EAX` (변환된 정수) |
| **`PrintRegs`** | 호출 시점의 `EAX`, `EBX`, `ECX`, `EDX` 값을 스택에 백업한 후 순차 출력 | **입력**: `EAX`, `EBX`, `ECX`, `EDX` |
| **`PrintHex32`** | 32비트 정수를 비트 회전(`ROL`)을 통해 8자리 16진수 UTF-16 문자열로 변환하여 출력 | **입력**: `EAX` (출력할 32비트 값) |

### 2. 핵심 구현 로직

* **문자열 $\rightarrow$ 정수 변환 (`WStrToInt`)**: 입력 버퍼 앞의 공백을 건너뛰고 부호(`+`, `-`)를 확인한 뒤, 각 자릿수에 `10`을 곱하며 누적합니다. 음수인 경우 `NEG` 명령어로 2의 보수를 취합니다.
* **16진수 변환 출력 (`PrintHex32`)**: `ROL EBX, 4` 명령어로 상위 4비트를 최하위로 회전시키고 `AND EDX, 0Fh`로 추출하여 `'0'~'9'`, `'A'~'F'` 문자로 변환합니다.
* **레지스터 보존 (`PrintRegs`)**: `WriteConsoleW` 호출 시 `EAX`, `ECX`, `EDX`가 변경되므로 함수 진입 직후 4개 레지스터를 모두 `PUSH`하고, `[esp]`, `[esp + 4]`, `[esp + 8]`, `[esp + 12]`로 원본 값을 읽어 출력합니다.

### 3. 연산별 레지스터 동작 규칙

각 연산 수행 전 `EAX = num1`, `EBX = num2`, `ECX = 0`, `EDX = 0`으로 초기화됩니다.

1. **덧셈 (`ADD EAX, EBX`)**: `EAX + EBX`의 결과가 `EAX`에 저장됩니다.
2. **뺄셈 (`SUB EAX, EBX`)**: `EAX - EBX`의 결과가 `EAX`에 저장됩니다.
3. **곱셈 (`IMUL EBX`)**: 부호 있는 32비트 곱셈 결과(최대 64비트)가 **`EDX`(상위 32비트) : `EAX`(하위 32비트)** 쌍에 나누어 저장됩니다.
4. **나눗셈 (`IDIV EBX`)**: `CDQ` 명령어로 `EAX`의 부호를 `EDX`까지 확장한 뒤 `EBX`로 나누며, **몫은 `EAX`**, **나머지는 `EDX`**에 저장됩니다.

## 실행 예시

`25`(16진수 `0x19`)와 `4`(16진수 `0x04`)를 입력했을 때의 출력 결과입니다.

```text
첫 번째 숫자 입력: 25
두 번째 숫자 입력: 4

[1. 덧셈 (ADD) 결과]
EAX = 0000001D   EBX = 00000004   ECX = 00000000   EDX = 00000000

[2. 뺄셈 (SUB) 결과]
EAX = 00000015   EBX = 00000004   ECX = 00000000   EDX = 00000000

[3. 곱셈 (IMUL) 결과]
EAX = 00000064   EBX = 00000004   ECX = 00000000   EDX = 00000000

[4. 나눗셈 (IDIV) 결과]
EAX = 00000006   EBX = 00000004   ECX = 00000000   EDX = 00000001
```

* **덧셈**: $25 + 4 = 29$ (`0x0000001D`)
* **뺄셈**: $25 - 4 = 21$ (`0x00000015`)
* **곱셈**: $25 \times 4 = 100$ (`0x00000064`)
* **나눗셈**: $25 \div 4 \rightarrow$ 몫 `6` (`EAX = 00000006`), 나머지 `1` (`EDX = 00000001`)

---

## 주의사항

* 두 번째 숫자(`num2`)에 `0`을 입력할 경우 나눗셈(`IDIV`) 단계에서 **0으로 나누기 예외(Divide by Zero Exception)**가 발생하여 프로그램이 비정상 종료됩니다.
* 입력값은 32비트 부호 있는 정수 범위(`-2,147,483,648` ~ `2,147,483,647`) 내에서 입력해야 합니다.
